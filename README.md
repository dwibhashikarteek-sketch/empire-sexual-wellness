# Empire Sexual Medicine & Wellness — public educational release

Website: https://dwibhashikarteek-sketch.github.io/empire-sexual-wellness/

This repository contains only the static educational website release and its publishing workflow. Staff software, patient records, private credentials and internal clinic systems are not included. Content delivered on a public website can be viewed and copied.

The owner-supplied clinic logo is included unchanged. Clinical content, translations, credentials and branding claims remain visibly marked for clinical, language and legal review. Owner permission to publish does not represent clinical or NMC approval.

There are 129 distinct topics, English guides and short Telugu/Hindi summaries, totalling 412 HTML pages. No patient forms, analytics, accounts or online consultations are provided by this static website. Hosting may retain access logs.

## Publish or update

Replace website.zip with the verified static publication bundle, preserving its root index.html, assets, language directories, robots.txt and sitemap.xml. The canonical base must match this repository’s Pages URL. Never upload staff software or patient data.

In Settings > Pages select GitHub Actions. The Publish educational website workflow runs on pushes to main and can also run manually. It extracts website.zip, uploads the static artifact and deploys to Pages. Check the successful run and live logo, language links and topic pages.

Indexing is permitted, but search inclusion, rankings and AI citations are not guaranteed. A verified Search Console property is needed for sitemap submission; it is not configured here.
